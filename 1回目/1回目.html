時空間データベース

本講義で私は、ドライブ・旅の軌跡アプリを作成する。

1. コンセプト

「ただの移動を、ドラマチックな旅の思い出に」

一般的なビジネス用・ライフログ用の位置情報アプリとは一線を画す、 ドライブと旅行が大好きな人のための「体験記録」アプリ。

2. メインターゲット

  • 週末によく遠出やドライブ、旅行をする人
  • 高速道路のSA/PAによく立ち寄る人
  • 「あの時寄ったあのお店、どこだっけ？」を後から楽しく振り返りたい人

3. 主な機能

① 賢い時空間トラッキング（高速道路・一般道の自動判定）

  • バックグラウンドで移動軌跡を自動記録する。
  • 移動速度や道路データから「高速道路を移動中」であることをスマートに認識する。

② SA/PA立ち寄り自動検知＆スタンプラリー

  • 全国のSA/PAに近づき、一定時間滞在すると自動で「立ち寄り確認」をポップアップする。
  • 寄った場所がコレクションされるスタンプラリー機能を実装する。
  • 高速道路の走破率メーターによってゲーム性を高める。

③ 「さっきの店」ピン留め＆タイムライン逆引き

  • 「さっき寄ったあのお店、名前なんだっけ？」という悩みを解決する。
  • 滞在履歴のマップをタップするだけで周辺スポットから店舗を特定できる。
  • 写真やメモと一緒に思い出を保存できる。

4. 時空間データの活用

  • 位置情報（空間データ）と時刻情報（時間データ）を組み合わせて移動履歴を管理する。
  • いつ、どこを、どのようなルートで移動したのかを可視化する。
  • SA/PAへの立ち寄り時間や滞在時間を記録し、旅の行動履歴として活用する。

5. 競合との差別化ポイント

既存アプリ（Googleマップ等） 本アプリ
味気ない「移動の線」と「点」 ドライブのルートが「旅のストーリー」として残る
SA/PAは単なる通過点扱い SA/PAが「目的地・イベント」になる
実用性重視（ナビや行動記録） エンタメ性重視（走破率・コレクション・思い出）

6. 使用する技術スタック

  • HTML
  • CSS
  • JavaScript
  • 位置情報API（Geolocation API）
  • 地図API（Google Maps API等）
  • ローカルストレージ
